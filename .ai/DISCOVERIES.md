# DESCUBRIMIENTOS — ZANTIA

> Hallazgos crudos de cada `/audit`, sin pulir. Cuando un hallazgo se confirma como estable y relevante, se destila hacia `.ai/ARCHITECTURE.md` (si es estructural) o `.ai/CURRENT_STATE.md` (si es de estado) — este archivo no reemplaza a esos, es su materia prima.

Todo hallazgo se etiqueta obligatoriamente (ver `.claude/rules/discovery-antes-de-modificar.md`):

- `[CONFIRMADO]` — verificado leyendo el archivo/comando directamente.
- `[INFERIDO]` — conclusión razonable a partir de evidencia indirecta.
- `[PROPUESTO]` — arquitectura o cambio futuro, no implementado.
- `[DESCONOCIDO]` — no hay evidencia suficiente; no se rellena con imaginación.
