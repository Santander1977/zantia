# INTEGRACIONES — ZANTIA

> Sistemas externos que ESTE proyecto consume o con los que se integra (automatización, mensajería, pagos, terceros). Distinto de `.ai/API_CONTRACTS.md` (lo que este proyecto expone).

| Sistema externo | Propósito | Cómo se integra | Quién lo mantiene | Secreto asociado (ver `.ai/SECURITY.md`, sin valores) |
|---|---|---|---|---|
| Chatwoot (canal WhatsApp real, vía webhook) | Canal conversacional principal del agente — recibe mensajes entrantes (`message_created`) y envía respuestas | Webhook entrante (`POST /webhook/chatwoot` en `service/app.py`) + REST saliente (`POST /api/v1/accounts/{id}/conversations/{id}/messages`) contra `CHATWOOT_URL`, con header `api_access_token`; envía y recibe el número de WhatsApp y el texto del mensaje del paciente — ver `.claude/rules/proteccion-datos-personales.md`. Conectado SOLO a un inbox de prueba, nunca al de producción de HRMM (recado 011) | Instancia de Chatwoot de este ecosistema (fuera de ZANTIA) | `CHATWOOT_API_TOKEN` |
| Telegram (canal alternativo real, vía webhook, recado 022) | Segundo canal conversacional — recibe Updates entrantes y envía respuestas vía la Bot API pública de Telegram | Webhook entrante (`POST /webhook/telegram` en `service/app.py`) + REST saliente (`POST https://api.telegram.org/bot<token>/sendMessage`, token en la URL, no en un header); envía y recibe el `chat.id` de Telegram y el texto del mensaje del paciente — ver `.claude/rules/proteccion-datos-personales.md`. Nunca conectado a un bot real en esta sesión (sin bot/token disponibles) | Bot API pública de Telegram (Telegram LLC, fuera de este ecosistema) | `TELEGRAM_BOT_TOKEN` |
| hrmm-backend (agenda real, otro proyecto de este ecosistema) | Disponibilidad/reserva/reprogramación/cancelación/consulta de citas reales, y resolución de identidad de paciente (`buscar-paciente`) — reemplaza `MockAppointmentService` cuando está activo | HTTP directo (`domains/health/hrmm_http.py`) contra `HRMM_BACKEND_URL`, con header `X-Backend-Secret`; envía y recibe datos personales reales del paciente (documento de identidad, nombre, teléfono) — ver `.claude/rules/proteccion-datos-personales.md` | Proyecto `hrmm` (fuera de ZANTIA) | `HRMM_BACKEND_SECRET` |
